五、Windows 系统详细安装步骤（全程文字详解）

步骤1：管理员身份运行安装包

找到下载的 navicat17_premium_lite_cs_x64.exe 文件，右键 → 以管理员身份运行（避免权限不足导致安装失败）；弹出“用户账户控制”时，点击“是”。

步骤2：同意许可协议

进入安装向导界面，阅读许可协议后，勾选“我接受许可协议中的条款”，点击“下一步”。

步骤3：选择安装路径（避坑重点）

  1. 点击“浏览”，自定义安装目录；
  2. ⚠️ 路径严禁包含中文、空格、特殊符号（如 D:\软件\Navicat 不可用，D:\soft\NavicatLite17 可用）；
  3. 推荐安装到非系统盘（如 D 盘），节省 C 盘空间；
  4. 确认路径后，点击“下一步”。

步骤4：选择附加任务

建议勾选：

  • ✅ Create a desktop icon（创建桌面快捷方式，方便启动）；
  • 可选：Add to PATH（添加到环境变量，支持命令行启动）；
    点击“下一步”。

步骤5：开始安装

确认所有设置无误后，点击“安装”；等待进度条完成（约 1-2 分钟，过程中勿关闭窗口）。

步骤6：完成安装（直接启动）

安装完成后，勾选“启动 Navicat Premium Lite 17”，点击“完成”，软件自动启动。

六、macOS 系统安装简述

  1. 从官网或网盘下载 .dmg 镜像文件；
  2. 双击镜像，将 Navicat Premium Lite 17 图标拖入“应用程序”文件夹；
  3. 打开“应用程序”，右键软件图标 → “打开”（首次运行需绕过 macOS 未知开发者限制）；
  4. 软件启动后即可正常使用，无额外激活步骤。

七、首次启动与基础使用（快速连接数据库）

1. 启动软件

双击桌面 Navicat Premium Lite 17 图标，首次启动无需激活、无试用期限制，直接进入主界面。

2. 连接 MySQL 数据库（示例）

  1. 点击主界面左上角 “连接” → 选择“MySQL”；
  2. 在连接设置窗口填写：
    • 连接名：自定义（如“本地MySQL”）；
    • 主机/IP：localhost（本地数据库）或服务器 IP；
    • 端口：默认 3306；
    • 用户名/密码：数据库账号密码；
  3. 点击“测试连接”，提示“连接成功”后，点击“确定”；
  4. 双击左侧连接名，即可展开数据库列表，开始管理数据。

3. 中文界面设置（默认中文，无需额外配置）

Navicat Premium Lite 17 官方原生支持中文，安装后默认中文界面，无需手动切换语言。

八、常见问题解决方案（安装/启动/连接报错）

问题1：安装时提示“权限不足”

  • 原因：未用管理员权限运行；
  • 解决：右键安装包 → 以管理员身份运行，关闭360/火绒等杀毒软件后重试。

问题2：启动软件闪退/无响应

  • 原因：安装路径含中文、.NET 框架缺失、系统版本过低；
  • 解决：
    1. 卸载软件，重新安装到全英文路径；
    2. 安装 .NET Framework 4.8 及以上；
    3. 确认系统为 Windows 10/11 64位。

问题3：连接数据库提示“连接失败”

  • 原因：数据库服务未启动、主机/端口错误、防火墙拦截、账号密码错误；
  • 解决：
    1. 确认本地/服务器数据库服务已正常运行；
    2. 核对主机 IP、端口、账号密码是否正确；
    3. 关闭本地防火墙，或放行数据库端口（如 3306）；
    4. 远程连接需开启服务器 SSH/SSL 权限。

问题4：macOS 提示“无法验证开发者”

  • 原因：macOS 安全机制拦截；
  • 解决：打开“系统设置 → 安全性与隐私”，点击“仍要打开”，或右键软件图标 → “打开”。
